Jolu Windows x86_64 免安装版

使用：先完整解压 ZIP，再运行 Jolu.exe，无需运行安装器。
运行环境：需要 Microsoft Edge WebView2 Runtime；如系统未安装，请从微软官网下载：
https://developer.microsoft.com/microsoft-edge/webview2/

账号、设置和历史数据仍保存在当前 Windows 用户的数据目录，与安装版共用。
此包不是把数据保存在程序目录的完全便携版；复制程序到其他电脑不会携带账号数据。

更新：此版本停用应用内更新，避免启动安装器。请退出 Jolu，下载新版 Portable ZIP，
解压并替换旧程序；保存在用户目录中的数据不受影响。
下载地址：https://github.com/meilule/Jolu/releases/latest
