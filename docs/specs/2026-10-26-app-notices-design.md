# 余额金额卡片与相关通知

鼠鼠选择「金额卡片」，并要求全部相关通知完整接入。此设计落实已经确认的外观和现有提醒类型。

- 前台：余额低于阈值用金额卡片，显示连接、余额、币种和阈值，点击查看账号定位对应账号；任务恢复、完成、失败沿用公共提示卡片并可查看任务。
- 后台：保留 Windows 系统通知，点击余额或任务通知打开对应账号或任务。系统通知不伪造自定义外观。
- 保留当前触发规则：同币种阈值、跌破一次提醒、回升后再次跌破可重新提醒、免打扰和任务通知开关。普通操作提示继续沿用已经完成的公共组件。
- 复用公共提示的透明外层、关闭、暂停、排队和状态色。余额卡片采用琥珀色钱包图标、明显金额、轻边框和阴影，不读取或展示密钥。
- 后端仅向主窗口发送提醒唤醒事件，主窗口读取待呈现提醒，订阅后立即补读，避免窗口初始化时丢通知。队列只存内存，不记录余额日志。
- 定位账号时进入供应商的账号管理，清除不相容筛选并滚动到目标卡片；目标已删除时明确提示，不修改账号或历史。

验证覆盖通知开关、前台/后台分流与失败回退、消息读取与非法输入、金额和币种、通知交互、账号定位和任务跳转。桌面验证只使用隔离数据与合成网关。
