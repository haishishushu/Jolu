# Jolu 全量前端样式与确认交互

## 依据与目标

鼠鼠已经确认 `docs/ui/Jolu.pen` 的 CC Switch 风格，并要求先写 MD、再完成全部前端。以当前设计稿为唯一视觉依据：纯色表面、细灰边、圆角和短投影，保留 Jolu 绿色语义、既有业务内容和确认流程。Git 中已有的 `Jolu.pen` 修改属于上一阶段，不覆盖或重写。

采用现有 React 19、TypeScript、Tailwind CSS 4 与 Radix Dialog，在原组件和共享样式上实施。另一种整页替换方案会重复已经接通的数据逻辑，增加回归风险，因此采用共享样式更新与逐模块核对。浏览器示例仍仅用于预览；桌面错误不回退到示例数据。

## 视觉落地

- `jolu-bg` 浅/深：`#FFFFFF` / `#0D0D0D`；`jolu-side`：`#FFFFFF` / `#141414`；`jolu-stage`：`#F4F4F5` / `#181818`。
- 卡片 `jolu-cc-surface`：`#FFFFFF` / `#181818`，边 `#E4E4E7` / `#2A2A2D`，1px；圆角通常 12–16px。
- 卡片短投影 `0 4px 5px`，色 `#00000018` / `#00000059`；控件 `0 1px 2px`，色 `#0000000D` / `#00000033`；弹窗 `0 10px 24px`，色 `#00000026` / `#00000080`。
- 中性按钮及绿色次操作使用实色表面、细边、短投影；主要操作绿色、最终删除红色，保留焦点、按下、禁用和加载状态。
- 主页面页签改成灰色分段轨道，4px 内边距和间距，12px 外圆角、8px 内圆角，选中白色/深色表面与短投影。仅改已在画布改为分段形式的页签，消息内容等内部页签沿用画布。
- 表单、菜单、弹窗、卡片使用明确的语义类；不通过全局 `div` 或通配选择器猜测元素身份。

## 确认弹窗矩阵

```text
操作入口 → 展示对象、影响与确认按钮
           ├─ 取消 / Esc → 不执行
           └─ 确认 → 锁定重复提交与关闭
                       ├─ 成功 → 更新数据并关闭
                       └─ 失败 → 留在原弹窗、显示原因、允许重试
```

| 操作 | 处理 |
| --- | --- |
| 单账号删除、替换使用中的账号 | 保留现有确认、对象和替代账号选择 |
| 两页面批量删除账号 | 保留选择快照、部分成功与仅重试失败项 |
| 取消运行任务、删除自动化任务 | 保留明确任务对象与影响的确认 |
| 删除 Skill、复制/导入同名冲突、离开未保存编辑器 | 保留现有确认及备份/冲突流程 |
| 插入基础模板覆盖编辑内容 | 有内容差异时增加确认；确认前不覆盖 |
| 数据清理、导入数据 | 保留清理预览与确认；导入沿用校验预览确认 |
| 删除模型入口分组 | 保留确认，执行期间禁止退出与重复提交 |
| 接入/断开 Agent、重新应用配置、接受外部配置 | 显示工具名称及配置影响；Codex/Gemini 保留专用接线说明；异步成功后关闭，失败允许重试 |
| 关闭模型转发 | 有已接入 Agent 时确认恢复原连接的影响 |
| 刷新网关 API Key | 改为弹窗说明旧 Key 失效；取消不刷新，失败保留并重试 |
| 销毁灵动岛 | 主页面和右键菜单均先确认；仅关闭目标窗口，账号与历史保留 |
| 紧急切回直连 | 保持一键紧急行为，避免额外阻碍恢复 |
| 搜索、筛选、页签、刷新、复制、清空选择、普通开关 | 不增加二次确认 |

确认使用现有 Radix Dialog，无新增依赖。打开时聚焦取消，焦点限制于弹窗；关闭恢复触发位置。危险确认不允许点击遮罩误触关闭；运行中取消、Esc、遮罩均不得卸载。不可把通知消息当作确认。

## 验收

逐模块对照 Pencil 截图与浏览器运行截图；浅深色都检查，覆盖供应商、账号、统计、会话、自动化、Skills、设置、签到、模型入口和浮动窗口。检查页签、卡片、表单、确认弹窗、禁用与窄窗口。运行 TypeScript 检查、前端构建及受影响业务逻辑测试；用浏览器验证新增确认的取消、确认、重复点击与错误保留。浏览器验收不宣称真实账号或桌面后端已验收。

不构建安装包，不修改后端协议，不执行 Git 暂存、提交、推送或分支操作。
