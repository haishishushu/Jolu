# 一键签到设计

## 目标与授权

在供应商下方增加同级「一键签到」，集中处理 WorkBuddy、Qoder、Trae 国内与国际发行版实际提供的每日福利。鼠鼠明确要求自主设计、开发、测试且不要询问；设计及常规实现取舍由小的决定。保留现有工作区修改，不进行任何 Git 写操作。

## 方案

复用供应商现有账号、Jolu.pen 的主窗口外壳、按钮和主题变量。新增独立页面，按国内/国际两行、三种平台三列展示六张卡片；每张展示关联的订阅账号、状态、平台当前奖励与单账号签到。页首提供刷新状态、一键签到和状态计数；页尾显示最近签到记录。

考虑过打开六个官方页面由用户逐个操作、后台每天自动领取、以及本次选择的手动批量领取。前者不满足一键操作，后者超出用户提出的入口及操作范围；选择手动批量、逐账号报告结果，不默认增加定时器、切换账号或新授权系统。

## 能力边界

- Qoder CN / Global：官方文档已确认每轮 100 Credits，UTC+8 10:00 换轮；实现需从官方客户端核对每日活动具体协议，不能领取非每日活动。
- WorkBuddy CN：官方发行代码提供每日状态与领取接口；WorkBuddy AI 发行配置显式 DisableCheckin=true，显示当前未开放，不发送签到请求。
- Trae CN：官方发行代码提供每日积分状态与领取接口，个人 MARSCODE 账号适用；须使用真实设备身份。国际版受官方 CN 区域守卫限制，显示当前未开放。
- 奖励数额、活动开放、已领取以服务端为准，绝不把未知显示为零或假成功。

## 状态与交互

状态分别表达：待查询、可签到、已签到、未开放、不支持、登录过期、无权限、限流、失败。顶部工具栏依次为隐藏账号、刷新状态、添加账号、一键签到。鼠鼠明确要求移除账号卡片加号；顶部「添加账号」先弹出供应商与版本选择，再在当前页复用供应商连接表单。「去连接」「更新登录」仍直接预选准确平台及版本，保存后留在原页刷新。暂停账号不参与。单个账号错误不终止其他账号；签到期间仅按钮显示加载并禁用重复操作，不展示页面内横向进度提示，完成后更新账号卡片与右侧结果通知。相同平台、版本、真实账号身份的重复连接需要去重，原工具登录和浏览器授权不得串用。后台领取前再查状态，仅可领取时发起一次领取请求；领取请求不自动重试，网络结果不明时说明需刷新核实。

手动点击「刷新状态」仅按钮显示加载，不展示页面内刷新进度条；完成后在右上角公共通知区显示状态汇总，账号部分失败用警告通知，总读取失败用错误通知，不打开居中弹窗或遮罩。首次进入、返回前台和定时只读刷新不通知。供应商选择仅列六个签到版本，WorkBuddy AI 自动活跃奖励与 Trae 国际未开放手动签到，标明能力并禁用选择，不连接无关供应商。选择项及签到卡片名称左侧均复用 22px 官方品牌图标，禁用项整体淡化，浅深色沿用现有品牌组件。

同一供应商同一版本允许浏览器授权多个独立账号，每个账号单独展示状态、签到及记录。同一官方身份重新授权时更新原连接，保留名称、创建时间和历史；不同身份或版本新增连接。账号必须通过本次官方身份校验，额度不支持、无权限或临时失败单独展示。保存期间冻结表单，阻止关闭、更换平台、重新授权和重复提交；保存失败保留输入。

## A 账号统计卡（鼠鼠已选择）

正式画板 145 / 146 在每个账号的今日奖励下增加双列「本周签到 / 本月签到」，分别显示签到天数与已领取奖励，下方显示累计签到获得及账户总额度、可用额度；原单账号按钮位于统计区下方，支持同平台多个独立账号。沿用 Jolu 浅深色变量，不增加页面横向进度条。

Jolu 本机统计按已保存的成功领取记录、真实账号身份跨连接去重，完整本机历史不受最近 50 条列表限制。周按北京时间周一开始、月按北京时间自然月，按实际领取时间归属；相同官方周期只计一次，缺周期时按北京日期去重。未来记录不纳入，未知金额、真实零、无记录及失败分别表达。官方能查询时优先展示官方项：WorkBuddy 接入官方返回日期中的周/月天数与本期活动原始累计，明确日期数组未承诺完整历史范围，周/月奖励未知；日期缺失时回退 Jolu 的项单独标来源。Trae 当前状态接口仅覆盖今日，Qoder 当前活动接口仅覆盖本轮，不能据此补造完整周/月历史。

账户额度独立查询，保留官方总量、已用、直接剩余和明确不限量。WorkBuddy 逐资源包返回原始值；Qoder 套餐、加购等范围分别列出，不能合并为虚假总额。Trae 同时展示积分汇总及各已知包，只有总量与已用齐全、相容时才返回 `calculated_remaining`，界面标「可用额度（计算）」，不能伪装成官方直接剩余或按百分比推算。未知项不补零，汇总与包不再相加。查询失败的旧值标过期。手动刷新先更新已核实身份的额度缓存，领取事件只刷新对应账号；离页不新发请求，换身份同步更新官方账号标签并清除旧统计及额度。

鼠鼠进一步要求：订阅表单「名称」改为只读「账号」，不需要手填名称；保存与卡片优先使用官方账号，无显示账号时使用稳定身份指纹，不泄露原 UID。API Key 服务名称保留原用途。宽屏每行四张卡片，窄屏逐级减少列数。每个已连接账号（含非手动签到版本）都有删除入口，确认后只移除对应 Jolu 连接和凭据，保留签到历史；失败保留原账号、执行中防重复与关闭。正式画板 145 / 146 对应四列卡片，147 / 148 对应删除确认。

最新调整以 149–160 为准：149 / 150 主卡统一保留今日奖励、周/月天数、总/可用额度；单一范围或官方明确汇总显示原值，多范围显示「多项额度」并在详情逐项列出，不能混加。底部按「详情｜签到状态或签到操作｜删除」排列，移除账号行更多菜单与重复状态；状态沿用官方当前轮次，不能把一次签到写成整月完成。151 / 152 为右侧账号详情，包含原完整奖励、累计、全部资源包、已用、计算来源、未知/失败/过期说明，不额外创建查询。单账号删除继续复用 147 / 148 的确认。隐私态不在详情或操作标签泄露账号；刷新重挂统计时保持该连接的详情，移除账号或离页时关闭。

账号管理和一键签到共用批量选择及删除确认。153 / 154 为签到批量态，155 / 156 为账号管理批量态，157 / 158 为两页共用确认，159 / 160 为部分失败结果。入口为「批量管理」，展开「全选当前列表、清空已选、已选数量、删除所选、退出」。账号管理按当前搜索、类型与供应商筛选的交集选择，筛选掉的选择永久清除；签到批量模式列出保存的所有连接，包括暂停、重复官方身份及版本未知连接。实际领取仍按官方身份去重，删除只按明确勾选的连接 ID。

确认时固定目标快照，显示账号、平台、数量及当前使用标记。仅移除 Jolu 连接及保存凭据，保留签到与用量历史、原工具登录；批量删除不挑选替代账号或切换 CLI。顺序处理，单项失败继续其他项；失败显示原因、保留原连接，仅允许重试失败项。执行期间冻结选择、关闭与重复提交；后台连接事件由原订阅处理，账号管理批次结束显式刷新一次，签到页关闭确认后合并刷新。隐私态用账号编号及固定失败提示，不回显原始错误。确认前取消不发送删除请求，全部成功关闭确认，部分失败可关闭并保留失败选择。

## 数据与安全

凭证只在 Rust 后端读取使用，不进入页面、记录或日志。请求地址为官方固定白名单，遵循 Jolu 网络设置，禁止携带认证跨域重定向。主窗口限制新命令；隔离验收不得读取真实登录或向上游领取。SQLite 仅增表保存脱敏记录，不修改第三方文件、已有账号、原始会话和统计数据。网络过程中不持有数据库锁；结果回写前核对账号快照，防止切换/删除后串号。
