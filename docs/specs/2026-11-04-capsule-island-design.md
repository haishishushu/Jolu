## 1. 目标

把浮动灵动岛窗口改成胶囊形态：

- 收缩时是一枚高 40 的胶囊。左侧是一颗小 bot，用眼睛表示状态；bot 外面两圈细环是 7 天（外）和 5 小时（内）额度。
- 双击后弹性展开为宽 380 的卡片，bot 放大到卡片左侧，额度环跟着套在外面，可以悬停、聚焦或单击固定某一圈。
- bot 的眼睛跟随鼠标，包括鼠标在灵动岛窗口之外的时候。
- 有会话写入时，bot 在「眼睛」和「本段 Token 消耗」两面之间自动轮播。
- 模型入口开启转发模式后，灵动岛显示已接线的 Agent，以及每次转发的去向和结果。

## 4. 形态与尺寸

| 形态 | 尺寸 | 内容 |
|---|---|---|
| 收缩胶囊 | 高 40、圆角 20，宽度随内容 200–420 | bot（32，含两圈环）· 平台名 · 5h / 7d 百分比 · 本段增量 · 已接线 Agent 头像 |
| 展开卡片 | 宽 380、圆角 28，高度随内容 | 头部（平台、接入方式、状态、切换）· bot 140 + 额度图例 · 会话列表 · 模型入口段 · 底部汇总 |
| 贴边迷你胶囊 | 高 32，宽度随内容（约 48） | bot（26）与额度环，写入中多一个绿点；悬停 400ms 恢复完整胶囊 |
| 分离气泡 | 40×40 圆 / 高 40 胶囊 | 2 个以上会话运行时显示会话数；接线漂移时显示「1 个接线需处理」 |

收缩 ↔ 展开：宽、高、圆角同时插值，弹簧曲线 `cubic-bezier(.32, 1.28, .48, 1)`，约 0.42s。内容在 160ms 后逐段淡入，每段延迟 40ms。收回顺序相反。

## 5. 交互

- 单击无动作；双击展开 / 收回；展开后点卡片外或按 Esc 收回。
- 拖动：按住拖动，靠近屏幕边缘松手即停靠，沿用现有 `island_drag` / `dock_release` 流程。
- 额度环（仅展开态）：
  - 悬停或 Tab 聚焦某一圈，该圈加粗到 1.35 倍，另一圈淡到 30%；bot 收起眼睛，屏幕显示这一圈的百分比、窗口名和重置时间。
  - 单击或 Enter 固定；再次单击、点图例或 Esc 取消。指针离开 300ms 后才恢复眼睛。
  - 每圈有读屏文字，例如「5 小时额度已用 10%，4h 51m 后重置。按 Enter 固定显示」。
- 右键菜单、分身、连接切换保持现有行为。

## 6. bot

### 6.1 表情

表情只由真实状态触发，不随机出现。眼睛颜色同时表示严重程度：白＝正常，绿＝工作，青＝刷新或转发，橙＝提醒，红＝阻断，灰＝离线。

| 表情 | 触发条件 | 动效 |
|---|---|---|
| 空闲 | 没有会话写入 | 每 4–6 秒随机眨眼 |
| 看向指针 | 指针悬停在胶囊上 | 跟随指针 |
| 工作中 | 有会话正在写入 Token | 绿色，左右缓慢扫视（1.6s 一个来回），并开启 Token 轮播（§6.3） |
| 刷新中 | 手动或定时刷新额度 | 两枚旋转的弧，刷新结束补完当前一圈 |
| 完成 | 一段输出结束（增量提示收起） | 笑眼 ^ ^ 停留 1.2s，外圈走一圈高光 |
| 惊讶 | 单段新增 ≥ 50k Token | 圆眼，轻跳一次，0.9s |
| 打招呼 | 双击展开 | 右眼 ^，0.9s |
| 被拖动 | 拖动窗口中 | > < |
| 贴边偷看 | 停靠在屏幕边缘 | 眼睛挤到朝屏幕内的一侧 |
| 担心 | 任一额度窗口 ≥ 80%，或网关拒绝请求 | 橙色，内侧上眼睑压低，环呼吸 |
| 沮丧 | 额度用尽（100%） | 红色，眼睛下垂；胶囊显示重置倒计时 |
| 出错 | 额度查询失败或连接过期 | 红色 × ×，左右轻摇两次 |
| 睡着 | 未连接，或 30 分钟内没有会话写入与网关请求 | 灰色闭眼，右上角 z 上浮 |
| 额度重置 | 额度窗口刚重置（已用比例回到低位） | 绿色星星眼，1.4s |
| 等待额度 | 自动化任务在等额度恢复 | 橙色半睁眼 |
| 转发中 | 请求正在经模型入口转发 | 青色，看向右侧 |

**优先级**（高到低）：出错 › 网关拒绝 › 沮丧 › 被拖动 › 担心 › 等待额度 › 刷新中 › 转发中 › 转发成功 › 工作中 › 一次性表情（惊讶 / 完成 / 额度重置）› 睡着 › 打招呼 › 贴边偷看 › 看向指针 › 空闲。

高优先级结束后回到当前最高的持续状态，不回放已经错过的一次性表情。

### 6.2 视线跟随

- 所有 bot 的眼睛都看向鼠标，包括鼠标在灵动岛窗口之外的时候。
- 偏移量：水平最多为脸直径的 13%，垂直最多 10%。鼠标距离 bot 中心越远越接近最大值，达到最大值的距离为 `max(80px, 脸宽 × 2.5)`。
- 每帧以系数 0.22 插值逼近目标，形成轻微的跟随延迟。
- 表情自带的偏移叠加在跟随之上。睡着时幅度乘 0.3，贴边偷看乘 0.4，被拖动乘 0.6。
- 开启「减少动效」（系统设置或 Jolu 外观设置）时直接对准，不插值。
- 鼠标离开桌面或窗口失去指针信息时，眼睛回到中位。

### 6.3 运行中 Token 轮播

- 只在「工作中」表情下开启。首轮先显示眼睛 2s，之后 Token 3s、眼睛 4s 循环。眼睛向上滑出，Token 从下方滑入，0.45s 弹簧。
- 展开态的 bot 显示完整数字「+16.4k」，下面写「本段 Token · N 个会话写入中」。
- 收缩态的脸不到 40px，放不下完整数字：显示 Token 时额度环淡出，脸放大到占满整个圆位，用短格式（`860` / `8.2k` / `17k` / `1.2M`，最多 4 个字符）。
- 惊讶、担心、出错等表情，以及额度环聚焦显示数值时，轮播暂停。贴边迷你态不轮播。
- 数字来自现有的本段增量（`useLiveUsage` 的 `deltaTokens` / `LiveCountsContext`），不新增数据源。

## 7. 数据与真实性

遵守 `AGENTS.md` §4：未知值、真实的零、能力不支持、查询失败、数据过期分别表达，桌面运行出错时不回退到示例数据。

| 场景 | 显示 |
|---|---|
| Auth 有两个额度窗口 | 两圈环 + 两个百分比 |
| 单额度来源 | 一圈环 |
| API 连接 | 不画环（避免把余额误读成额度），显示今日 Token 与今日费用；估算费用前加「约」并转橙，取不到显示「—」 |
| 额度查询失败 | 环保留空轨道，表情为出错，胶囊写「查询失败 · 双击查看」 |
| 未连接 | 空轨道，表情为睡着，平台名降为 50%，写「未连接 · 双击查看」 |
| 来源没有可信运行状态 | 会话区标题写「最近活跃会话」，不称为运行中，不开启 Token 轮播 |

额度环的长度、颜色阈值（< 80% 绿/青，≥ 80% 橙，100% 红）与现有 `authQuotaRows` / `quotaBarClass` 的判定保持一致，判定逻辑抽成纯函数复用。

## 8. 模型入口适配

只在模型入口处于转发模式（`proxy_mode = relay`）时出现。观测模式或转发关闭时，本节所有元素都不显示。

### 8.1 现有数据（已核实）

| 数据 | 来源 | 说明 |
|---|---|---|
| 路由流水 | `backend/src/gateway/route_log.rs`，由 `gateway/wire.rs` 的 `record_route` 每次请求写一行 | ts、agent、请求模型、来源 slug、上游模型、状态码、结果（ok / rejected / failed）、耗时；保留 1000 行，`gateway_route_log` 命令返回最近 20 条 |
| 接线状态 | `gateway_status` 返回的 `wiring[]` | 每个 Agent 的 wired、state、drift（pending / removed / changed / foreign） |
| 网关状态 | `gateway_status` | mode、enabled、port |

已知限制，界面必须照实表达：

- 被拒的记录 `source` 为空，只写原因，不写来源。
- 耗时是到响应头的时间，不是首字时间，界面写「耗时」。
- `agent` 可能为空，显示「未知 Agent」。
- 写流水用 `try_lock`，数据库忙时这一条会丢。

### 8.2 显示

- **常驻**：胶囊右侧叠放已接线的 Agent 头像，最多 3 个，超出显示 +N，按最近一次经网关的时间排序。
- **请求进入**（依赖新增的请求开始事件，见 §9）：bot 转青看向右侧；胶囊内容换成「Agent → 来源/模型 · 转发中」，底部一条青线流动；额度环换成被调用来源的额度；发起请求的 Agent 头像描青圈。
- **转发成功**：笑眼，显示 ✓ 与耗时，停留 2.4s。收回后，该 Agent 头像右下角留绿点 10s。
- **被拒**：担心，显示原因（「冷却 42s」「凭据已失效」「额度已用尽」「已暂停」），停留 4.8s。网关不会换到别的来源，界面不暗示自动切换。
- **接线漂移**：胶囊右侧出现橙色气泡「N 个接线需处理」。
- **展开态「模型入口」段**：
  - 标题行：「模型入口 · 转发中」和端口。
  - 每个已接线 Agent 一行，右侧写「最近一次 来源/模型」（取自路由流水，不是固定绑定）。正在转发的一行描青并显示流动线；漂移的 Agent 标橙，带「修复」按钮，跳到主窗口接线页。
  - 底部：今日经网关次数、成功数、被拒数（从路由流水按当天统计），以及「打开模型入口」。

### 8.3 不做

- 额度用完后自动换来源：后端未实现（路由组属于第 4 阶段），不画。
- 「某 Agent 用了某来源多少 Token」：路由流水没有 Token 数，`requests` 表没有 Agent 字段，给不出准确数字，不显示。

## 9. 后端改动

| 改动 | 原因 |
|---|---|
| 新增全局指针位置推送 | 灵动岛是小的透明窗口，DOM 事件只覆盖窗口内部。用 `AppHandle::cursor_position()`（Tauri 2.12，返回桌面物理坐标）在灵动岛窗口可见时以约 30Hz 采样，位置变化才向各灵动岛窗口发事件 |
| 路由流水写入后推送事件 | 现在只能每 15s 轮询 `gateway_route_log`，转发动效需要实时 |
| 新增请求开始事件 | 现在只在请求结束后写流水。没有这个事件时，动效从「转发成功 / 被拒」开始 |

事件只带元数据（时间、Agent、来源 slug、模型、结果、状态码、耗时），不带提示词与凭证。
