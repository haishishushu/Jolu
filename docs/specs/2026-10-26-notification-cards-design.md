# 操作提示卡片

鼠鼠已确认右上角通知卡片方案，并授权全部按方案实施。范围为主窗口公共操作提示；删除、清理等确认框继续居中，后台提醒沿用现有 Windows 系统通知。

## 方案选择

- 顶部居中轻提示：靠近主操作区，但容易遮挡筛选和表单。
- 右上角卡片：适合管理工具，可同时呈现多个独立结果。采用此方案。

## 展示与交互

- 主窗口右上角、标题栏和页面工具栏下方；右侧 20px，卡片宽 360px，小窗口留 16px 边距。
- 使用现有主题背景、边框、阴影与状态色，彩色图标配轻色底，正文保持正常文本色；12px 圆角。
- 标题一行结论，原因默认最多两行，较长内容可展开。右上角关闭按钮；可处理的错误支持动作入口。
- 成功与普通信息停留 3 秒，警告 6 秒，错误持续显示直至手动关闭或处理。悬停与键盘聚焦分别暂停，全部离开后按剩余时间继续。
- 同时最多 3 张，更多消息排队，开始显示后才计时；重复内容合并并显示次数。新成功不能覆盖旧错误。
- 淡入与短距离位移约 180ms，退出 140ms；减少动效时取消位移。不抢焦点。
- 使用共享组件让现有调用统一生效，不添加依赖。无法安全重试的操作不自动重试。
