## 设计与实施顺序

1. 新增 `gateway/subscription.rs`：按连接 ID 读取完整加密授权；禁止退回当前登录账号。轮换授权以旧凭据作比较条件，账号身份不变，事务更新快照、连接凭据和指纹。
2. Codex 生产适配器读取选中连接的授权，刷新后写回该连接，不改原工具 auth.json。保留合成上游注入供测试。修正 Chat 流式协议与 Responses 混用问题。
3. Claude 用选中连接的快照创建一次性隔离配置，清理认证/地址覆盖环境；运行官方 CLI，禁用内置工具与外部 MCP，退出后清理。每次传入完整对话，生产请求不借用其他账号的本机会话。修复可执行文件和 stream-json 参数；不支持的协议能力明确拒绝。
4. 后端提供来源接入能力与具体原因，前端来源卡片显示状态，来源选择与调用就绪分离；允许所有官方订阅开启选择，授权和适配未就绪时单独展示具体状态。已保存授权不等于已完成真实调用验收。
5. 对 Gemini、WorkBuddy、Qoder、Trae、ZCode 分别核对现有代码及公开资料，记录调用通道、身份隔离和待验证项；有实现依据的适配器先用合成上游验证，真实账号可用性保持待验收；没有完整协议的来源可以选择但不得宣称能调用。

## 验证

- 合成 A/B 账号，确保选中 A 不会读/写 B；缺少授权、刷新冲突和身份变化须明确失败。
- 本地模拟上游验证 Codex 请求凭据与流式/非流式协议；假 CLI 验证 Claude 隔离配置、环境、参数和清理。
- 前端能力状态测试、类型检查；后端网关和授权相关回归。
- 不调用真实模型、不读取真实登录文件做验收、不提交或构建安装包。

## Qoder / Trae 实际转发续轮

本轮目标是模型请求通过所选订阅账号完成协议转换和转发，不能以来源开关可选代替完成。

1. 分平台核对官方客户端的认证、模型请求、会话和流式协议。仅查公开资料与程序文件，不读取原工具真实账号数据。
2. Qoder 国内/国际与 Trae 国内/国际分别保留地区边界，凭据从对应 connection_id 解封。缺少完整授权时明确失败，禁止借用当前原工具登录。
3. 如需官方客户端桥接，使用一次性配置及工作目录，隔离环境、凭据存储、会话和工具，限定命令参数。禁止任意工具执行、继承用户插件或读取真实 keyring。
4. 刷新必须验证同一账号身份并以旧密文作比较条件，迟到结果不得覆盖用户重新登录；失败或取消也需清理临时资源。
5. 接入网关协议分派、能力查询和模型目录。隔离测试覆盖 A/B 账号、两个地区、并发/会话、刷新冲突、错误脱敏、缺失授权与异常流终止。
6. 测试仅用合成凭据、假客户端或本地模拟上游。官方协议证据与模拟结果分别记录；真实账号验收、真实模型权限及额度扣减另做。
7. 不构建安装包，不提交或推送。

续轮实际实现：Qoder 使用官方 OAuth 换 jobToken 后驱动隔离 CLI；Trae 使用官方随包 SDK 的 ChatCompletion HTTP 端点。当前均明确限定非流式；Trae 模型由调用方指定，订阅 JWT 是否获该端点接受仍待真实验收。根路由发送前及订阅锁等待结束后均须复查来源状态。协议依据、隔离测试和剩余边界见同日两个平台验收记录与 `2026-11-04-subscription-api.md`。

## Trae 对话重写阶段（取代上文旧 SDK 当前状态）

- 已接入账号目录的 function / __dev / token 上限 / 图片与思考档位白名单，新请求固定到地区模型主机的 `/api/agent/v3/llm_utils_chat`，上游使用 SSE，兼容下游 Chat 与 Messages 的流式和非流式。
- 已接入原生工具快照和明确 delta、部分文本工具解析、工具历史转换；所有工具直到明确完成且通过截断/混合协议检查后才释放，异常 EOF 不作为成功。
- 独立审查发现思考历史被拒、关闭思考提示不准和缓存字段丢失，已用失败测试复现并修复；后续自查修复缓存子集口径、文本工具提前输出及 Messages 异常 EOF 误报成功。
- Ruling: Messages 起始事件的 input_tokens / output_tokens 保留协议占位零，不把它们写入账号统计；官方 SDK 将两字段定义为必填，当前 Chat 上游通常只在末尾给出用量。末尾缺失数字仍有协议兼容占位零的限制，不能宣称所有客户端都能区分未知与零；后端归账仅保存实际已知字段。避免为此缓冲整段回答破坏实时流式，代价是客户端中途显示值未必是最终用量。
- Ruling: 思考历史用 `<think>` 文本兼容表示保留，不宣称原生思考历史；显式禁用思考因目录未声明该能力而准确拒绝。真实协议兼容待验收。
- Ruling: 模型池不再退回手填 Trae 模型；对话要求当前账号目录中的路由，避免保存一个 ID 就冒充可用模型。不删除旧保存值或历史数据。
- Ruling: 选路暂按 __dev 和思考档位简化评分，不等价参考插件的名称多数票、misnamed 与 Max 派生；Max 不公开。完整 GLM/DSML 等文本工具模板仍待接入。
- 会话使用进程随机盐、连接 ID、授权密文和调用方会话键隔离；无会话头时回退首个用户内容，同账号独立对话若首条内容相同可能共享会话；重启后不续用旧 ID。分桶账号锁和目录锁等待边界仍保留。
- 验证：本轮追加修复前网关 168 项通过；缓存、工具、EOF 修复后网关 172 项通过。随后补本地 Messages 请求→Trae 模拟 HTTP→Messages 回复回环，最终验证结果见同日 Trae 验收记录；仍未真实账号验收。无 Git 写操作，无安装包。
