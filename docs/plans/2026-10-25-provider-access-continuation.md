# 供应商账号接入与持续审查

本轮依据鼠鼠新要求继续执行，不重新请求已明确授权的功能确认，不执行 Git 写操作。

## 范围与实现选择

- Trae、ZCode：优先公开官方文档及官方程序现有登录复用；只读查询、不自动登录、不发模型请求、不写回授权、不获取无权访问的服务数据。缺登录列入待验证项。
- 自定义供应商余额：鼠鼠明确要求支持，覆盖画板29A原先“不支持查询”的能力规则；布局沿用账号页余额区，不擅改设计稿。只向用户配置的同一服务发送凭证，支持已知网关协议及有公开依据的官方余额端点；未知接口明确不支持，不提供任意脚本执行。
- 其他功能：重点审查统计导入、会话与存储的数据完整性，证实缺陷后最小修复。
