# 一键签到实施计划

> 使用 Superpowers：平台研究并行；实现按共享合约推进；完成后独立代码审查。鼠鼠已明确免除澄清与审批等待。禁止 Git 写操作。

**目标：** 在供应商下方新增同级签到入口，实现已核实的每日领取能力。

**架构：** Rust 固定官方适配器负责状态和领取，公共服务校验账号、并发去重及 SQLite 记录。React 页面复用现有组件，顺序处理批量领取并呈现逐项结果。

**技术栈：** 现有 React 19 / TypeScript / Tauri 2 / Rust / reqwest / rusqlite，不增加产品依赖。

**设计说明：** docs/specs/2026-10-27-daily-checkin-design.md。

## 约束与审查重点

- 不读取 .pen 文件原文，只用 Pencil；不得泄露登录数据，不切换/提交/重置 Git。
- 正式运行不回落模拟数据；未知、零、禁用、失败分开。
- 不同区域、重复连接、领取跨天、设备已领取、领取超时、运行时账号变化重点检查。
