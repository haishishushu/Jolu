# 全供应商默认浏览器登录与六版本目录

鼠鼠明确授权：现有全部订阅供应商都支持独立浏览器授权；WorkBuddy、WorkBuddy AI、Trae CN、Trae、Qoder CN、Qoder 分别列出。保留本地读取入口，全部浏览器登录由操作系统默认浏览器处理。

## 实现

- 展示供应商与统计平台分开：新增 ProviderId，保留原 PlatformId、连接 ID、历史统计；目录、计数、筛选、弹窗和账号名称按版本。后端 DTO 返回非敏感 edition，旧浏览器账号仅在后端解封自身凭证提取版本，不做破坏性迁移。
- 延续已通过的 WorkBuddy / Qoder 登录；补 Trae 官方 PKCE 与 loopback，Grok 官方设备流，ZCode 官方 CLI 设备轮询。Claude / Codex / Gemini / OpenCode 使用官方协议或独立临时 CLI profile，只运行登录、不发模型请求、不覆盖原工具配置。
- 统一授权状态、取消/超时、真实账号与额度校验、Windows DPAPI 保存；设备码等公开登录提示可显示，令牌与授权 state 不出后端。
- 本地读取严格按选定区域探测和登记，修复页面 wrapper 丢失 edition；所有外部程序与网络工作位于数据库锁外。
- 自定义供应商没有统一身份服务，仍按用户配置的 API Key 连接；不能为任意地址伪造 OAuth 协议。

## 验证与边界

- 各协议的来源、解析与失败状态采用针对性测试；目录/筛选/同名规则先红后绿。
- 集成完成后统一类型检查、前后端必要测试、真实组件验证；需要鼠鼠手动登录时再提示。
- 不输出凭证、不改 Git 状态；官方服务异常和未完成真实登录分别记录，不能以打开页面或放开按钮宣布完成。
- Pencil MCP 当前仍提示文件未在编辑器打开；复用现有卡片/弹窗结构，不修改 .pen，视觉对照缺口独立保留。
