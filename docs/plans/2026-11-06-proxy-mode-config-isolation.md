# 代理模式配置隔离修复计划

> 执行方式：使用 superpowers:executing-plans，在本次会话内完成修复与验证。

**目标：** 中转模式不再通过观测代理的旧上游记录重写 CLI 地址，避免地址与认证凭证混用。

**方案：** 将配置跟随与孤儿清理中的文件操作分离出 Tauri 事件通知，使用运行时模式约束配置所有权。中转模式只使用网关接线快照还原地址与凭证，观测模式继续保留现有透明接管行为。

**技术栈：** Rust、现有 settings::Store、proxy_config 与 gateway::escape，不新增依赖。

**依据：** 本次实际复现的 401、proxy.rs 观测回调与 gateway 模式分流约定。

## 约束

- 修改鼠鼠指定的 D:/develop/cc-usage，工作区初始干净。
- 不变更 UI、用户密钥或数据库结构，不构建安装包。
- 测试使用临时目录和子进程，不触碰真实 CLI 配置。
- 已获授权提交与推送，使用现有本人身份，提交信息加 [skip ci]。

## 检查重点

- 中转模式带旧观测上游时，外部切换供应商的地址与密钥保持配对。
- 已接线的本地地址不能被观测孤儿清理改回旧上游。
- 观测模式继续跟随外部供应商切换并保留认证字段。
- 运行时模式优先于正在切换中的设置值。
- 退出中转模式时按接线快照还原，不调用只还原地址的观测路径。
