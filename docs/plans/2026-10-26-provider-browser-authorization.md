# 本地登录与浏览器授权真实接通

鼠鼠已明确要求继续实现，不仅开放按钮：优先 WorkBuddy 401 和 Qoder 国内版，提供“读取本地登录信息”和“浏览器授权”两个入口，需要人工登录时再通知。

## 实现选择

- Qoder 国内/国际：直接读取对应官方客户端的 safeStorage 登录；浏览器授权使用官方公开设备授权（PKCE + nonce + 轮询），不覆盖原工具登录。
- WorkBuddy：使用官方桌面端的 state 创建、令牌轮询和账号验证协议，系统默认浏览器打开官方返回且经域名校验的 authUrl；必须经真实账单接口验证后才能保存。
- 全部浏览器授权统一调用系统默认浏览器，不指定 Chrome / Edge，不创建内嵌网页窗口，不读取其他浏览器的 Cookie 数据库。
- 所有凭证留后端。浏览器新授权先留内存，用户保存连接时用当前用户 DPAPI 封存到 connections.secret；前端仅返回状态、账号展示信息与不含凭证的授权 ID。
- 授权取消、超时、换平台和迟到响应不能产生已连接账号；保存后查询按该连接自己的凭证执行，不借用其他本机或浏览器账号。
- 复用现有连接弹窗、账号卡片和状态区；不修改 Jolu.pen。Pencil 当前读取仍提示文件未打开，视觉对照单独记录，不据旧界面重新设计。
