# 签到卡摘要与详情实施计划

鼠鼠要求卡片固定展示统一摘要，详细数据点击详情查看，并调整删除按钮位置。本轮沿用现有数据和四列布局，不改供应商协议、统计口径或保存的账号。

- 主卡固定保留今日奖励、本周/本月天数、总额度/可用额度。一个范围显示原值；明确的 Trae 汇总优先，多个独立范围显示多项额度并进入详情，不拼合不明总额。查询失败与过期保留简短状态。
- 账号行右侧由独立垃圾桶改为「⋯」账号操作，菜单只有删除账号，危险项为红色；原确认、冻结、防重复和历史保留继续复用。
- 底部为「详情」次按钮及签到主按钮。右侧详情面板展示原有完整周/月奖励、累计/活动奖励、所有额度范围、已用与计算来源、失败和范围说明；不重复发起额外数据查询。
- 详情开关由账号卡持有，不因同一连接的身份刷新重挂统计组件而丢失；账号移除后关闭。隐私态标题、菜单与详情均隐藏账号。
- 按鼠鼠既有自主实施授权直接完成，不执行任何 Git 写操作。
