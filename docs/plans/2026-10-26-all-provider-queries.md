# 全供应商账号查询实施计划

鼠鼠已确认范围：额度、余额、套餐、重置卡全部查询。沿用账号卡片和现有只读查询，不自动登录、不消费重置卡、不发送模型请求，不执行 Git 写操作。

## 实施与验收

- [x] 修复 WorkBuddy 新版加密登录兼容：通过对应官方客户端运行时在内存中读取，限制协议、超时与输出，不落盘凭证，不跨版本换号。
- [x] 取消自定义供应商及 API 连接被平台名单提前拦截；按地址、凭证和服务真实响应查询额度、套餐、余额。
- [x] 所有已查询账号均可刷新重置卡信息，服务未返回时明确说明；不推断其他平台存在 Codex 重置卡。
- [x] 读取 WorkBuddy 真实返回的套餐字段，保留未知值和真实零，验证错误状态与账号归属。
- [x] 定向 Rust / 前端测试、类型检查、真实组件验证；逐平台记录真实验证与缺少账号/接口的条件。

## 已确认限制

- 任意平台不一定同时具有余额、订阅或重置卡，统一查询入口不能创造服务端不存在的数据。
- Qoder 国内版不能借用国际版 CLI 登录；官方 API 普通 Key 不能当作管理凭证。
- Pencil MCP 当前未打开设计稿，读取调用失败；本轮不重新设计卡片、不修改 `.pen`。
- 工作区已有大量改动，保留既有内容，只修改本任务涉及的位置。

实施与真实条件结果见 `docs/verification/2026-10-26-all-provider-queries.md`。已完成入口和兼容修复，不代表所有平台均返回全部字段；真实服务与设计稿对照的剩余条件单独保留。
