# 账号统一操作区与两页批量删除验收

## 本轮范围

- 签到账号底部并排「详情｜真实签到状态/签到｜删除」，删除入口不再藏在账号行更多菜单。现有单账号确认与右侧详情继续使用。
- 账号管理和一键签到共用批量入口、选择 hook、确认弹窗和逐项删除 helper。仅处理确认快照中的选中连接 ID，不按相同官方身份扩大删除范围。
- 账号管理筛选清理不可见选择；签到批量模式显示全部已保存连接，含暂停、官方身份重复及未知版本，普通领取的身份去重保持。
- 成功项移出选择，失败项保留并说明，重试只提交失败项。同步 ref 防连点，执行中禁止关闭、改选或新增连接；后端现有引用保护继续生效。
- 保留签到/用量历史和原工具登录，当前使用连接明确标注。批量删除不调用 enable；原单个账号可选择替代的流程保持原用途。
- 隐私模式确认列表使用编号，错误使用固定安全提示，不回显任意后端错误；账号管理复选框具备隐私感知的可区分标签。

## 边界

本轮仅修改前端批量交互和合成验收，无 Rust 或供应商协议改动，未重复全量后端测试。所有删除使用合成内存账号；未删除真实账号、未领取真实奖励、未改变 CLI 登录、未执行 Git 写操作。本轮通过不能补充第二个真实 Trae 账号的登录/领奖证据，该缺口仍按既有验收记录保留。
