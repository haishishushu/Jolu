# 账号功能与项目审查记录

日期：2026-10-25。范围是本轮工作区整体整合，包括开始时已存在的供应商查询修改；不把已有功能算成本轮新建。全程未执行 Git 写操作，未修改真实登录、重置卡或设计稿。

## 改动总结

- 账号页：API 套餐 Key 接入额度查询；额度和余额独立展示，不再互相遮盖；真实剩余次数（包括零）优先展示。五小时、周、订阅状态、到期时间、重置卡和「设置为使用」沿用现有设计区块与能力边界。手动刷新只更新对应连接，加载、失败和过期状态明确区分。
- 数据来源：整合 Gemini、OpenCode OpenAI 订阅、WorkBuddy、ZCode 套餐与网关查询；新增 Qoder 官方 CLI 控制协议查询。缺失值、非法值、真实零、接口不支持不混用；sub2api 的有效订阅到期时间接入元数据，不能用它猜续费状态。
- 请求安全及性能：套餐路由改为 HTTPS 官方主机与路径边界校验，忽略查询参数中的域名；移除向六家供应商盲试同一 Key 的路径，减少无效请求并防止错发凭证。原生查询也走统一状态收尾；查询结束时在同一数据库锁内核对凭证，换 Key、暂停或删除后的迟到响应不能污染新状态。
- 真实联调收尾：智谱明确的无套餐响应精确匹配为「当前凭证未关联 Coding Plan」，未知业务错误继续失败；智谱、MiniMax、ZenMux 不再透传上游自由错误文本，只显示固定文案和数字业务码，防止回显凭证。
- 数据保护：Skills 覆盖先完整暂存再交换，失败恢复，拒绝自身/嵌套覆盖；自动化运行固化创建时配置，编辑只影响后续新运行，详情、额度、队列、续跑与会话跳转使用相同快照；旧运行缺快照时保留历史并要求人工处理，停止计时。删除连接前保护活动/暂停任务和未结束运行快照的引用。
- 更新：检查、下载、取消、验签、安装及重试已有实现，本轮核对并跑组件回归；修复发布清单漏 Windows 条目或 Windows 指向 Linux 包仍通过校验的问题。正式更新开关继续按仓库规范默认关闭。

## 平台能力与实测边界

| 平台/来源 | 当前代码能力 | 本轮真实验证/限制 |
|---|---|---|
| Codex | 官方登录额度、服务返回的五小时/周窗口、重置卡；本地订阅记录带来源与观察时间；保存完整授权后可设置为使用 | 只读查询成功，当前响应仅有周窗口及重置时间；不伪造缺失的五小时数据。实时订阅状态/到期授权仍受服务权限限制 |
| Claude | OAuth 额度；API 套餐按明确地址路由；网关额度/余额；完整授权快照与失败恢复 | 本机配置指向智谱套餐服务，旧 sub2api 专用 smoke 返回404、钱包专用 smoke 不满足前置条件。实际套餐GET返回HTTP200、业务码500、success=false，明确无Coding Plan。修复分类后真实复查为unsupported；没有凭空得到额度，也未切换真实账号 |
| Gemini | Google 登录的模型额度与套餐信息；内存刷新，不写回登录 | 本机返回 unauthorized，无成功登录样本；API Key 不保证有额度接口 |
| OpenCode | OpenAI 登录额度及重置卡；Go API Key 套餐；既有本地会话统计 | 真实 OAuth/Go 账号缺样本；重置卡和套餐卡片完成合成回归 |
| WorkBuddy | 桌面登录积分与已知套餐数据，缺字段保持未知 | 本机只读返回 ok、1 个积分窗口；接口未公开，仍有版本变化风险 |
| Qoder | CLI 1.1.78 起的国际版登录，通过官方 SDK 同款控制协议读取账号额度 | 本机 unauthorized；合成子进程协议通过；国内版在线额度未接入 |
| ZCode | BigModel Coding Plan Key 与明确套餐来源；普通模型 API 接入 | OAuth 缺私有认证依据；真实 Key 仍待样本验证 |
| Grok | 已有本机 OAuth 额度解析与查询 | 本轮自动测试覆盖解析，未新增真实授权查询 |
| Trae | 本机来源检测 | 设计 29 明确不能凭图标或登录推断额度；加密登录态与个人/企业接口边界待确认 |
| 自定义供应商 | 模型连接验证 | 画板 29A 明确不查询额度/余额；改变此范围需先确认设计 |
| new-api / one-api / sub2api | 同配置地址的余额/用量；new-api读取公开站点换算比例，不固定假定比例 | 合成回归通过；不能保证所有私有分支兼容，也不能把普通官方 API Key 当作余额授权 |

不同服务没有统一的五小时/周/重置卡机制，所有卡片都有字段位置不等于服务提供这些字段。未知值不会填零、满额或虚构到期日。

## 性能观测

本轮消除了未知套餐 Key 的跨供应商盲试，没有重写已实现的页面懒加载。生产主窗口 chunk 为 71.56kB（gzip 23.43kB），公共 main 为270.75kB（gzip85.14kB）；这些是构建尺寸，不是本轮收益百分比。

隔离 debug 桌面进程树1分钟5次采样均响应：工作集约730–775MiB、私有内存约384–430MiB；报告 `output/acceptance/performance-2026-10-25.json`。采样包含WebView子进程和开发热更新，期间仍在其他构建/测试；不能据此证明长期无泄漏或正式安装包内存性能。没有为缺基准的会话正文读取引入长期缓存。
