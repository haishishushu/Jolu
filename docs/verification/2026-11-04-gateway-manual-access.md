# 模型入口：两行状态条与手动接入 Key

## 用户确认范围

- 顶部改为两行：第一行通俗说明模型转发状态与开关；第二行网关地址、API Key、复制与刷新。
- 刷新仅撤销手动接入 Key，一键接入的工具保持可用。
- 不构建安装包，不执行真实账号请求，不修改真实 CLI 配置。

## 实现

- `GatewayAccessBar.tsx`：地址含 `http://`；Key 仅显示掩码；复制与刷新均有结果反馈。刷新前就地确认，读取失败可重试，浏览器预览禁用密钥操作。
- `gateway/access.rs`：32 字节系统随机数生成 Key；Windows DPAPI 按当前用户加密，SQLite 单行原子替换。明文不进入前端、普通日志或状态 DTO；复制由 Rust 写系统剪贴板。
- 手动接入首次开通后，公共请求接受当前手动 Key 或已登记的一键接线 token。此前未开通过手动接入的安装保持原行为。Bearer、`x-api-key`、`x-goog-api-key` 三种请求头均支持。
- Codex 保留 OAuth 的专用端点须有接线记录，且请求 token 匹配本机当前登录 token；刷新手动 Key 不影响它。内部桥接回调沿用原有本机访问规则。Host / Origin / Referer 防护保留。
- 刷新后旧 Key 的后续请求返回 401；已开始处理的请求不强制中断。只手动填写过旧 Key 的工具需要重新粘贴。
- 加密存储沿用项目 Windows 用户保护能力；其他平台当前不提供手动 Key，显示读取失败，不降级保存明文。
