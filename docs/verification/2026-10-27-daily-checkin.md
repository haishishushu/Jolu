# 一键签到验收记录

日期：2026-10-27（Asia/Shanghai）。本轮不执行 Git 写操作，保留开始时已有的通知、账号与设置修改。

## 改动总结

- 供应商下方增加同级「一键签到」，支持默认打开与上次访问恢复；首次访问懒加载，访问后保留挂载，切页不打断已开始的批量操作。
- Jolu.pen 新增模块 I、133–138 六块浅深色主页面、空状态与规则画板，模块目录及全部主窗口侧栏同步入口；颜色复用既有 jolu 变量。
- 六版本卡片复用已有供应商账号，支持单账号、批量、刷新、进度、隐私隐藏、错误分流与最近 50 条记录。相同账号身份合并，暂停/未知版本不参与领取；失败后继续其他账号。
- Rust 三个平台适配器复用既有凭证读取，只访问固定官方地址；主窗口命令限制，身份哈希去重，提交页面已查询的账号身份；领取前及真正发送前复查连接和原工具身份，禁止自动重试和跨域重定向。
- SQLite 仅增加 daily_checkin_records 表和时间索引。记录不含凭证、用户原始 ID 或设备身份；零奖励与未知奖励分别保存。未知响应不标成功，领取结果不明必须先查询。
- Qoder 以官方 HTTP Date 和北京时间 10:00 轮次判断；Trae 以官方时间及北京时间自然日判断，前端使用服务端剩余时间，避免客户端时钟偏移。WorkBuddy 时区无官方确认，不按本机日期缓存已签。

## 审查与回归修复

1. 查询期间暂停、删除、重授权：初版会在网络后才核对。新增发送前连接快照复核，回归证明零领取调用；Qoder 内部二次 GET 完成后还会执行最终发送门禁。
2. 页面 A 就绪后原工具切 B：前端发送 expectedAccountKey，后端与实际解析身份比对，变化时取消；回归先红后绿。
3. WorkBuddy 默认 HTTP 重试：显式 retry::never，与其他两个适配器一致。
4. 系统时钟偏差：Qoder 使用官方 Date，前端按相对有效期；服务端 23:55、本机快十分钟的回归保持可领取，缺官方日期保持未知。
5. 旧趋势测试在凌晨失败：样本 now-1h 跨到昨天，查询 today 无桶；两项改固定本地正午，相关 12 项与完整 Rust 测试通过，无业务统计改动。
6. 主面板首次加载停住：初次窗口隐藏状态查询可晚于就绪回调，造成 active 一直 false。就绪后重读窗口状态并拒绝迟到查询；合成启动回归先超时失败、修复后通过，8 页真实桌面全部通过。
