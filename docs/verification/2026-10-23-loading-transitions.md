# 骨架加载与界面切换过渡

## 问题原因

原有骨架延迟 150ms 才显现，等待时会出现空白；内容过渡只从 85% 不透明度开始，首次挂载不播放，感知较弱。Skills 的详情与编辑分支没有挂载动画引用。页面级位移会临时改变内部 fixed 弹窗的定位参照。

## 改动总结

- 首次无数据时立即显示骨架，等待期间持续动效；数据就绪后以 220ms 透明度过渡呈现。不增加人为等待，也不在已有缓存时强制插入骨架。
- 首次打开主页面与切页共用淡入，移除容器位移。连续切换从当前帧接续，兼容 StrictMode 首次副作用重放以及系统/应用减少动效。
- 账号骨架对应四列布局，日历使用月份与七行格子占位。日历只运行整体动效，避免每格分别运行动画。
- 补齐 Skills 列表、详情、编辑之间的过渡。后台刷新不改变内容标识，保留数据、焦点及输入，不触发整页淡入。
- 合并上一轮开关打磨：设置、Skills、主窗口灵动岛设置共用开关，等距留白、圆点阴影、更大点击区域与浅深色交互反馈。

## 验证

- 修改前，隔离回归明确复现骨架延迟为 0.15s；修改后通过。
- `node scripts/acceptance/loading-transition.cjs`：首帧骨架、慢请求、数据淡入、后台刷新保留输入、页面淡入且不改变 fixed 定位、错误结束骨架、减少动效、StrictMode 首次播放。
- `pnpm --dir frontend typecheck` 通过；motion / queryCache 共 7 项测试通过。
- Edge 7 个主页面、统计子页、按钮过渡、深色及减少动效巡检通过；开关鼠标/键盘、禁用、等距几何与双主题验证通过。
- 通过 Pencil 截取画板 30、38 对照布局。截图位于 `output/acceptance/loading-skeleton.png` 与 `switch-light.png` / `switch-dark.png`。未改动设计文件。
