# 账号管理：四列卡片与身份隐私

- 设计稿：Jolu.pen 07/08 为浅深色展示态；09/10 为 Codex 筛选及隐藏态。
- 卡片固定每行四列、间距 16px，订阅元信息和额度纵向排列。同步时间单独一行，操作用带提示的图标按钮，避免窄卡片挤压。
- 连接自定义名称正常显示；邮箱 / 账号及 Base URL 用 28px 高浅底标签承载。隐藏时原文替换为圆点和锁图标，DOM、title 和无障碍标签不保留原值。名称本身包含邮箱时也隐藏。金额、套餐、额度、模型与原有脱敏 Key 不受影响。
- 隐藏偏好保留在当前设备；搜索支持邮箱。没有账号身份数据时显示“邮箱 / 账号未获取”，不从名称或 Key 猜测。
- 后端新增可空 account_email 列。新连接保存本机匹配身份，旧连接读取列表时仅回填未获取项；只有本机完整凭证匹配才关联邮箱。支持既有 Claude Code / Codex 登录解析，其他来源未知时留空。
- 更换凭证时清除或更新旧邮箱；更名、暂停不会改变已记录邮箱。隔离验收环境禁止读取本机身份。API Key 与完整令牌始终不返回前端。
